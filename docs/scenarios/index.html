이기종 산출물을 표준 계약으로 잇는 통합 시스템

컨소시엄 6개 기관이 따로 만든 모듈(이기종 산출물)을 — 메타파머스 매니퓰레이터, 에이지로보틱스 모바일 플랫폼, 대동로보틱스 측위, KIRO·농업과학원 엔드이펙터 — STATION은 6종 표준 계약으로 이어 붙여 하나의 동작하는 로봇/플릿으로 통합한다. 조합 경우의 수가 폭증해도, 통합을 반복 가능·자동·손쉽게 만드는 것이 이 소프트웨어의 본질이다.

주관 메타파머스 공동 에이지로보틱스 공동 대동로보틱스 공동 KIRO 공동 국립농업과학원 위탁 UNIST 관제 비아

A. 무엇을 · 무엇으로 잇는가 — 6종 표준 계약

서로 다른 기관 노드 산출물을 "같은 언어로 말하게" 하는 6개의 이음새. 각 계약은 module_id 스파인에 묶인다.

통합 데이터 스파인

module_id→ Capability Protocol Telemetry Firmware Calibration
work_session_id→ Command Event Incident Result

Audit Package가 한 모듈의 통합을 한 번 검증하면 — 이후 동일 모듈은 어디서나 같은 방식으로 붙는다(반복성).

B. 이런 경우가 굉장히 많다 — 그래서 표준 통합

조합 폭증

로봇 1대 = {모바일 × 매니퓰 × 엔드이펙터 × 측위/맵 × 펌웨어} 조합. 작업유형·온실·버전까지 곱하면 수백 가지.

2 모바일 × 2 매니퓰 × 2 엔드이펙터 × 3 측위 × 3 펌웨어
= 72 기본 조합
× 작업유형(2) × 온실(3) = 432+ 경우

통합 비용: 맞춤 O(N²) → 표준 O(N)

모듈 쌍마다 개별 연동하면 페어가 폭증(빨강). 각 모듈이 표준 계약에 한 번만 맞추면 조합은 레지스트리 매칭(초록·추가개발 0).

맞춤 ~N²/2 페어
표준 N회(+신규 O(1))

→ 신규 기관/노드 합류 비용 O(N) → O(1). plan.pdf 성과지표 "다중 로봇 통합관제 시스템 구축"·비아 2차년도 "통합관제 SW 시제품"과 직접 연결.

조합 구성기 — 직접 이어보기

각 기관 산출물을 골라 한 대의 로봇을 조립하면, STATION이 6종 계약을 자동 매칭·호환성 검증(게이트)한다. 불일치는 사유·해결행동과 함께 자동 차단된다.

이 조합은 72가지 중 1 통합 가능

C. 통합 시나리오 8종 — 장소·순서로 보는 "잇는" 행위

생애주기 6종(개발실→사무실→시뮬→관제실→온실→현장) + 통합 패턴 2종(신규 기관/노드 합류 · 버전 업그레이드).
