비아의 역할 = 모든 로봇을 SDV로 개발할 수 있는 토대를 만드는 것

온실 멀티로봇 과제는 첫 적용 사례(reference deployment)일 뿐. 진짜 산출물은 로봇 종류와 무관한 SDV/SDR(Software-Defined Robot) 플랫폼이다 — 어떤 로봇이든 결국 노드 구성의 차이이고, 비아는 그 노드들을 표준 계약(이음새)으로 잇는 Local Agent + Contracts + HMI/Telemetry/관제를 robot-agnostic 코어로 제공한다. 아래 컨소시엄(에이지·메타파머스·대동…)은 그 코어 위에 올라간 인스턴스 프로파일이다.

계약 = 기관 간 정식 인계면
에이지 MCU ↔ 메타 ACU (Command/Signal) · 대동 LPU → 메타 ACU (측위 Signal) · 메타 내부(ACU↔VPU↔매니퓰) · 전 노드 → 비아 Telemetry/관제(업링크) · 비아 HMI(조작·게이트). 새 기관/노드는 표준계약 1회 등록(O(1))으로 합류 — HMI는 앱만 추가, 재개발 0.
1단계 — 계약 + 모델 ✅@station/contracts · 노드/기관 owner_org · 런타임 인터페이스 (완료)
