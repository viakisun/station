일반 주기 (General Notes)
  1. 치수 단위 mm. 일반공차 ISO 2768-m.
  2. 전 부품을 단일 판넬(600×400×4)에 부착 — 디스플레이·카메라 포함, 외부 거치대 없음.
  3. 보드 고정 M2.5/M3 스탠드오프 11mm. 디스플레이 면브래킷, 카메라 전방 브래킷.
  4. E-stop은 물리 회로로 모터 전원/enable 차단(SW 비의존). MCU·Agent는 보고만.
  5. CAN 버스 양끝 120Ω 종단, 선형 토폴로지, 분기 최소.
  6. star ground 1점 접지. 모터 전원과 컴퓨트 전원 도메인 분리.
  7. 모든 케이블·단자·보드 라벨 부착(NODE-*·24V/5V/GND·CAN/ETH).
  8. 권한 우선순위: 물리 E-stop > Agent 정책 > HMI > Cloud > ACU.
